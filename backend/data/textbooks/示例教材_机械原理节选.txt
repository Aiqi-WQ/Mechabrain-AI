第1章 平面机构的自由度

平面机构是由若干构件通过运动副联接而成的、各构件之间具有确定相对运动的系统。两构件之间直接接触并保持一定相对运动的联接称为运动副。按接触形式分为低副与高副：面接触的转动副与移动副为低副，点或线接触的凸轮副、齿轮副为高副。低副引入两个约束、保留一个自由度；高副引入一个约束、保留两个自由度。

平面机构自由度计算公式为 F = 3n - 2p5 - p4。式中 n 为活动构件数（不含机架），p5 为低副数目，p4 为高副数目。以铰链四杆机构为例：机架 1 个、活动构件 3 个，转动副 4 个，无高副，故 F = 3×3 - 2×4 - 0 = 1，与原动件数目相等，机构具有确定运动。曲柄滑块机构同样是 n = 3、p5 = 4，自由度也为 1。

使用公式前必须先处理三种特殊情况。其一为复合铰链：k 个构件在同一处铰接，实际构成 k-1 个转动副，若按一个计算会漏掉约束、导致自由度偏大。其二为局部自由度：凸轮滚子绕自身轴线的转动不影响输出运动，计算时应把滚子与凸轮视为一个构件后再统计。其三为虚约束：重复限制同一运动的约束（如平行四边形机构的附加杆、两构件间重复的移动副）应从 p5 中扣除，否则自由度会被算小。忽略这三项是自由度计算题最常见的失分点。

具有确定运动的条件是：机构自由度数等于原动件数目，且 F 大于零。当 F = 0 时系统为静定桁架，F 小于零时为超静定结构，均不能成为机构。

第2章 齿轮机构与传动比

齿轮机构用于传递回转运动与转矩，具有传动比准确、效率高、结构紧凑、寿命长等优点。按两轴相对位置分为：直齿圆柱齿轮（两轴平行）、斜齿圆柱齿轮（两轴平行、传动平稳）、圆锥齿轮（两轴垂直相交）、蜗杆蜗轮（两轴垂直交错）。

标准直齿圆柱齿轮的基本参数为模数 m、齿数 z、压力角 α（标准值 20°）。分度圆直径 d = m z，齿顶圆直径 da = m(z+2)，齿根圆直径 df = m(z-2.5)，标准中心距 a = m(z1 + z2) / 2。模数已标准化，是齿轮几何尺寸计算的核心参数，模数越大轮齿越粗壮、承载能力越高。

一对齿轮的传动比等于两轮转速之比，也等于齿数的反比：i12 = n1 / n2 = z2 / z1。设 m = 4 mm、z1 = 20、z2 = 60，则 d1 = 80 mm、d2 = 240 mm，标准中心距 a = 4×(20+60)/2 = 160 mm，传动比 i12 = 60/20 = 3，即主动轮转三圈从动轮转一圈，从动轮转向相反。

斜齿圆柱齿轮除端面参数外还有法面参数，二者通过螺旋角 β 换算：mn = mt cos β。斜齿轮重合度大、啮合平稳、噪声低，但会产生轴向力，需用一对旋向相反的斜齿轮或推力轴承平衡。蜗杆传动可实现很大的传动比（常见 10 至 80），结构紧凑且能自锁，但效率较低，约为 0.7 至 0.8。
